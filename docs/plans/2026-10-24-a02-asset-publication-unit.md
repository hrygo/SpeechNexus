# A02 首个资产发布单元

基线 `e09abad`；对应 [A02 #21](https://github.com/hrygo/SpeechNexus/issues/21)。
本单元交付共享 workspace 与首个实际 Asset 上传/元数据/内容路径，验证对象发布、
幂等、未知结果及保留期清理；不把整个 A02 或 G1 标为完成。

## 路线与依赖

1. `0003_assets` 在同一权威 PG/schema 增加 workspace、Asset、幂等意图、只追加的
   私有对象版本、受控引用及内容删除账本。保留既有协调表/数据/权限。默认 workspace
   由迁移建立，不引入用户或多租户。运行角色按用途获得最低 DML，无持久 DDL。
2. 在私有有界临时缓冲中完整接收内容，计算实际长度和 SHA-256。领域层定义内容、
   状态和引用规则；application 只依赖窄 metadata/object/inspection 端口。校验失败
   保留 rejected 事实，不能产生 ready 空内容或假媒体参数。
3. 短事务预留幂等意图和 Asset 身份，事务外写私有版本化对象、读回验证，再以原身份
   原子发布数据库引用。对象 key/version 不进入公共 DTO，不接受客户端 URL/key/path。
   连接/提交/对象确认未知时查询原身份，不补造新对象或重复发布。
4. 实现 `POST /v1/nexus/assets` 与两个 GET 路径，按冻结契约校验 multipart、DTO、
   幂等和单 Range；服务端端点/凭据只来自配置。对象客户端限定固定 origin、禁用
   重定向和普通写入重试，避免向其他端点发送内容。事务不包围对象或内容检查。
5. 首个已发布资源即接入引用/过期 tombstone 和持久删除账本。过期关闭新引用/公开
   内容；物理清理必须核对引用，固定对象版本/摘要，事务外删除，确认后记完成。
   未知上传/在途引用保持待协调。显式用户删除的预检/确认协议仍由 A07 后续完成，
   本单元不提供绕过预检的公开删除入口。

## 分段边界

首批实际内容校验以 `text_input` 为验收入口。音频 `asr_input` / `voice_reference`
的真实媒体检查通过具名 inspection 端口接 B03；缺少该能力时明确拒绝，不能制造
ready 音频、假 duration/采样率/声道或永远没有消费者的“正在校验”任务。音频联调、
Artifact/Operation/receipt、不可变模型/声音/预设/发音资源继续按后续单元推进。

上传可显式设置契约范围内 TTL。省略 TTL 时的部署默认保留期尚待用户选择；实现
保留配置入口，测试使用显式策略，不把测试值当成生产默认。未知结果恢复不重新读取
可变默认值覆盖原请求的有效配置。

## 验证与交接

- 合成字节与项目隔离 PG/MinIO：成功、rejected、空/超限/摘要错、同键同内容/异内容、
  并发竞争、对象确认丢失、DB 确认丢失、失败清理、重启读取和跨版本删除。
- Range/过期/引用与清理、固定 origin/重定向拒绝；不向公网发送测试内容。
- 真 PG 迁移/非 owner 角色与原有双库协调回归不跳过；CI 增加可复现 MinIO 前置，
  保留全部既有保护检查。类型/生成漂移、源契约、Web/Python 和安装镜像按改动验证。
- 提供合入 SHA、迁移 head、配置/消费样例、B03 inspection 依赖和实际验证范围。
  MinIO root 只用于隔离服务建桶/测试，不作为生产对象 IAM 最低权限已验收的证据。

# 开发工作台

负责边界清楚的 Web / Workbench 与正式客户端接入，交付可用的业务状态和交互体验。

> 本页是派工简报；与[共用边界](common.md)一起用于 subagent 或当前会话，不构成平台岗位、模型配置或权限。

## 实施边界

- 使用契约角色提供的公开协议与生成类型；工作台只消费语音协议，不共写底座表、直连私有引擎或私造字段。共享契约、持久 intent / 幂等身份、CAS 与协调事务缺口交具名维护者处理。
- 先稳定复现，按候选仓库 `web/AGENTS.md` 选择实现与检查。重点覆盖上下文切换后的迟到响应、刷新恢复、取消未知、过期、加载 / 错误和键盘焦点。
- 成功状态绑定当前上下文和实际公开生产者；fake、正式后端、浏览器及设备覆盖分别报告，不以页面演示证明真实推理和发布。
- 通用构建留在指定开发环境，GPU 经批准协议消费。只在获准 checkout 内执行许可的构建和编辑，继承受管工具与缓存；命令被拒绝时交宿主处理，不换写法、改 HOME / PATH 或扩大权限绕过。

## 实施交付

向非作者 reviewer / QA 提供固定候选、复现步骤、协议 / 生产者版本、交互变化及适用检查。设备、采集权限和物理网络由适任环境验证；保留宿主所管理的活跃缓存和共享临时目录。

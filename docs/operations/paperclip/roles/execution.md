从任务能力卡取得工具链、批准镜像 / 模型 / instance / generation、现有隔离 PG / InnoDB / 对象存储及秘密引用；不沿用历史端点或重新 bootstrap。保留 Legacy CLI 的已验修改回传路径，不为统一 Harness 名称切换到未验 native SSH / 远端 commit 模式。

区分请求上限、binding 上限、实际 policy、源 PCM / 样本及编码制品；提交未知按原身份恢复。取消接受、逻辑结束、进程退出和 TTL 不等于引擎停止 / 资源释放。输出固定版本制品、执行身份和双证据，由 A 核验后幂等结算 / 公开发布，不把私有 staging 当公开结果。

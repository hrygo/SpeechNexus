# ASR 原稿导入与固定修订文本下载

工作台文件转写页从已确认的成功 ASR Job 选择结果。结果的制品与回执须匹配
`Job.artifacts` 中的 transcript；用户显式进入项目稿件页、选择项目并命名后，
才提交现有 `TranscriptCreateRequest.source.kind=speech_artifact`。
入口切换只传制品/回执引用，不下载正文或创建稿件。

## 来源、封存与恢复

工作台后端只从服务端配置的公开语音路由读取 Artifact 和内容。原有身份、
workspace、kind、ready、receipt、过期、长度及 SHA-256 校验继续适用。
支持 UTF-8 `text/plain`，以及生成校验器接受的 `Transcription` JSON；后者
对应网关 [文件 ASR 结果](../../execution-gateway/src/speechnexus_gateway/application/file_asr_result.py)
的 `{"text": ...}`，只提取原文，不将 JSON 标记变成稿件正文。
不猜测其他 JSON 格式，不接受重复字段、非法 Unicode 或 NUL，不改写空白和换行。
来源原始字节上限仍为 4,000,000，正文上限仍为 1,000,000 个字符。

通过验证的原文由既有事务保存为 sealed 初始修订；校对追加 draft 修订，保留
原稿及来源。读取网络内容不占持久化事务。原键命中已提交结果时不重新读取来源。
工作台通过公开协议消费语音，不直接访问引擎或共写语音表。

编辑器在外发前持久保存完整创建请求及原键。导入未知时，重新载入不自动写入，
只允许显式原键重放；待恢复的原请求来源优先于新入口传入的来源。存储失败、
未保存手工正文或校对草稿不会被新导入覆盖。导入前尚未确认的入口引用仅存内存，
刷新后可从原 ASR Job 重新进入，不构成一次已提交操作。

## 固定版本 TXT

稿件页下载已通过生成边界和身份/修订校验的服务端快照，文件名包含所读修订，
内容是该修订的精确 UTF-8 字节，不包含未保存草稿。恢复缓存须重新核对后才能
下载；历史修订可以独立读取并下载。将下载交给浏览器后撤销本地对象 URL。

TXT 不包含时间轴。字幕导出仍需与正文修订关联的合法时间证据，不按字数构造
时码，也不把 JSON、TXT 或合成浏览器验证视为字幕能力。

## 证据边界

来源适配器的合成 HTTP 单元验证、隔离 PostgreSQL 的封存/校对/恢复/导出验证，
以及生产 Web 包加合成 HTTP 的原键恢复与原生 TXT 下载验证各有独立范围。
这些入口不使真实 ASR 工厂、A 端发布/预算、公开持久 Job、模型质量或目标部署
自动就绪；真实闭环继续按阶段计划 T07/T08 验收。

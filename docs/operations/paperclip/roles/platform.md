# A 契约与集成

本岗与[共同正文](common.md)和私有部署 overlay 编译为 runtime。负责公开契约 / 同源生成链、权威状态与协调事务、复杂持久恢复、跨层装配及本机集成。按当前任务选择相关项目技能，不把全部技能或全库测试作为局部任务前置；领域不维护独立 DTO 语义副本。

向 B 交固定资源 / 有效命令 / 输入资格及同版时序正负例，向 C 交正式端点、生成客户端和错误 / 恢复样例。共享契约、生成物、迁移、锁文件、组合根与同一测试文件由任务指定一名写者串行接入；缺某个输入给出具名解除条件，不要求整个上游工作包关闭。

优先在本机完成适用静态、合成与 macOS 检查。Linux 沙箱、CUDA 及现有隔离持久验证交 B 按同一候选取证，不给 Mac 复制测试秘密，不复用共享生产库。MLX / SpeechRail 的本机成功不授予 SpeechNexus Linux GPU 资格。

实施、集成和审查是分开的活动窗口。审 B 时先取得固定字节和原始证据，核对关键反例；参与被审候选实施后不能自签。自己的高风险改变交获准非作者 Sol。报告已实现、生产接线、实际验证、未验项及下一接收方，取得消费者实际接入回执。

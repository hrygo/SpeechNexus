# 故障窗口与恢复决定

选与本次操作相关的行即可。先由当前契约确定 owner、原身份和允许状态，再据观察选择动作；本表不新增错误码或恢复 API。

| 故障窗口/观察 | 需要核对的权威事实 | 恢复决定与禁止副作用 |
| --- | --- | --- |
| 外发前本地/数据库持久记录失败 | 是否能证明尚未外发；是否保留完整意图 | 可证明未发才允许纠正输入；没有恢复记录时停止新的外发 |
| 已外发，断线或超时 | 原身份的持久结果；请求是否可能已生效 | 保留 unknown，查询或契约允许的原请求/原键重放；不能换键普通重试 |
| 先 unknown，后一次重放被入口拒绝 | 原命令结果是否被权威处理 | 后一次 403/限流等只描述该次请求；不证明第一次失败或不存在 |
| 固定资源 GET 返回期望内容 | GET 是否携带原命令身份与结果语义 | 相同资源内容不证明该命令的结果，仍按原身份恢复 |
| 同键原请求在版本推进后再次到达 | 原结果是否先于新命令 CAS 查找 | 返回原结果；不能把原成功变成当前版本冲突 |
| 同键但正文/目标/默认解析不同 | 完整有效意图与幂等作用域 | 拒绝冲突；不能只比较键、摘要片段或资源名称 |
| 对象已写私有 staging，引用事务失败/未知 | 对象身份与原发布事务结果 | 先查原结果；未确认前不公开、不盲删可能已引用对象；孤儿按受控策略回收 |
| 完成事务已提交，回复丢失 | 原 Job/命令的持久终态 | 保留原成功与制品；禁止 catch-all 改写失败或再次生成 |
| 停止请求被接收或 TTL 到期 | 对应执行/实例/generation 的停止及释放事实 | 继续协调/隔离；旧 generation 或单个接收回执不能释放当前预算 |
| 旧响应晚于页面/资源切换 | 本地所有权 epoch 与服务端固定身份 | 忽略当前展示更新，保留原命令可恢复性；本地 abort 不等于远端回滚 |
| 删除预检后依赖/版本变化 | 当前目标和完整依赖快照、原命令是否已接受 | 新命令拒绝陈旧计划并重新预检确认；已接受原命令按原身份恢复，不重解释为新删除 |
| 恢复备份并重新开放内容 | 删除账本的重放完成事实 | 先应用账本；不复活已删内容，不追删跨模块独立副本，不删除执行/计量证据 |

## 推演时的最小记录

可以用短段落或表格，不必建立新框架：

`原身份/意图 → 故障发生在哪次提交之后 → 已知事实与 owner → 尚未知事实 → 允许下一步 → 必须保持的副作用/账目 → 证伪断言`

如果无法指出“错误实现会在哪条断言上失败”，验证通常仍太弱。例如“抛出了超时”不能证明没有重复执行；应观察真实提交之后原结果重放、持久行/对象身份和业务效果次数。

## 层次与装配

- 事务规则由领域/应用裁决，经窄事务端口落地；适配器实现锁、条件更新与事务，不能提供任意跨表状态修改来逃避裁决。
- 数据库约束、行锁和角色权限验证各有保护范围；schema 通过不证明跨表规则和恢复链路完整。
- 工作台、语音、网关、控制器分别拥有不同事实。不要因为链路跨 owner 就拆成无协调双写，也不要让消费者越权修改对方表。
- Node=1 仍使用同一持久协议；进程内锁、共享目录或重新加载默认配置不能代替集群恢复设计。

权威入口按需阅读：[协调事务](../../../../docs/architecture/coordination-transactions.md)、[执行及数据生命周期 ADR](../../../../docs/decisions/0005-complete-execution-and-data-lifecycle-contracts.md)、[存储可移植性 ADR](../../../../docs/decisions/0006-cluster-coordination-and-storage-portability.md)。这些文件规定预期，生产组合根与实测证明实现。

## 维护与评测

保留能区分正确恢复和危险重试的少量场景；变更提交边界、幂等语义、generation 或删除规则时复测。先比较实际决定和持久结果，再判断技能是否改善任务表现，不测试固定措辞。

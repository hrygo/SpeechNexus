# SpeechNexus 故障恢复设计

使故障后的决定与权威事实一致：不重复副作用、不覆盖已提交结果、不提前归还资源、不让旧结果污染新上下文。只实施当前请求授权的改动；分析任务输出设计与证据缺口。

## 找到决定恢复行为的事实

针对本次操作列出足以做决定的四项，不机械审计全部系统：

1. **原身份与完整意图**：操作/资源/版本/generation、幂等作用域、完整有效请求及固定资源。摘要用于比对，不能替代可恢复的原请求；重启后不重新读取可变默认值重建意图。
2. **权威所有者**：谁能确认命令是否提交、执行是否停止、对象是否发布或删除。客户端缓存、HTTP 接收回执和控制器观察各自只证明自己的事实。
3. **提交边界**：本地保存、数据库事务、outbox、远端调用、对象写入、公开引用分别在哪里不可逆；标出每次外发前的持久意图与未知窗口。
4. **允许改变的状态**：哪些事实可以进入 succeeded/failed、哪些仍 unknown/quarantined，预算何时允许释放。按有效契约裁决，不从当前代码的错误补偿倒推契约。

按需从 [AGENTS.md](../../../AGENTS.md)、[契约索引](../../../contracts/README.md)和[事务设计](../../../docs/architecture/coordination-transactions.md)定位当前定义；涉及执行命令看[执行命令](../../../docs/architecture/execution-command.md)，涉及资源释放看[运行治理](../../../docs/architecture/runtime-governance.md)，涉及删除看[删除生命周期](../../../docs/architecture/data-deletion.md)。不把文档的“设计要求”表述成“当前实现已支持”。

本技能负责恢复决定与故障窗口。实际改变机器契约时结合 [speechnexus-contract-change](../speechnexus-contract-change/SKILL.md)；改变协调事务端口、锁序、预算或 DDL/权限时结合 [speechnexus-coordination-change](../speechnexus-coordination-change/SKILL.md) 完成落地验证。现有协议和事务未变的客户端恢复修正不加载整套数据库流程；已完成的推演与共同检查直接复用。

## 沿故障窗口选择动作

用[故障推演表](references/failure-windows.md)展开相关窗口；只分析本次会改变的路径。

- **结果未知**：保留原身份与完整意图，按契约查询原命令或显式原请求重放。只在契约允许的已知失败/拒绝后创建新意图。后一次入口拒绝、资源固定 GET 或超时不能自动结算之前的未知提交。
- **幂等与 CAS**：先识别原结果，再按契约处理新命令 CAS；原结果重放不受后来版本变化误伤。相同键不能承载改动后的意图；不静默换键、重基或把“当前最新”当作原确认。
- **提交后补偿**：把可补偿的生成/私有对象失败与权威完成事务分开。完成可能已提交但回执丢失时，先查原结果，不能普通异常分支把成功覆盖成失败。
- **取消与释放**：区分用户取消、HTTP abort、停止请求、匹配身份的停止证据和实际资源释放。TTL/租约到期/任务终态不是算力已停止证明；未确认时保留账目并按契约协调隔离。
- **旧响应与重启**：取消本地等待不宣称服务端回滚；旧资源/版本/generation 响应不得更新新上下文。恢复依赖持久事实与轮询，不能只依赖进程内状态或一次通知。
- **发布与删除**：对固定版本/摘要重新校验依赖，私有 staging 与公开引用分开提交。删除确认不能套用于变化后的依赖，恢复先应用删除账本；独立副本按其所有权保留。

遇到缺少原请求、原身份结果入口或匹配停止事实的情况，说明需要哪个 owner 提供什么事实；继续不依赖它的工作，不编造安全重试或释放结论。

## 让错误恢复方案在测试中暴露

按风险选正常、并发和故障路径，重点验证持久状态与副作用，不仅检查异常类型：

- 真正提交后再丢回执，随后重放：只出现一次业务效果，返回原结果；不能只在提交前抛错模拟这个窗口。
- 同键同意图、同键不同意图、不同键竞争同版本：分别证明恢复、拒绝和 CAS，不以顺序 fake 替代要求的数据库并发。
- 隐藏/切换/重启后旧结果到达：原命令仍可恢复，新上下文没有被改写。
- 取消与完成并发、错误 generation 的停止证据、对象成功而数据库结果未知：核对各 owner 的事实和资源账目。

使用现有隔离测试入口和合成数据；需要真实持久化时验证真实事务结果，模型、目标拓扑和物理设备资格另记。测试脚本、日志和公开错误只保留必要元信息，不泄露原命令正文或业务内容。

交付一个与任务规模匹配的恢复决定：事实/窗口、允许动作、禁止副作用、验证结果及剩余未知。技能不要求每次写新计划，也不新增用户确认步骤；既有授权边界继续生效。

## 保持技能耐用

协议字段、状态机和事务入口从当前源头读取；示例只用于故障推理，不成为新的协议副本。发现契约或实现变化时核对引用并复测 [evals/evals.json](evals/evals.json) 中相关行为；实测记录放忽略目录，不固化当前测试数量、运行端点或版本。

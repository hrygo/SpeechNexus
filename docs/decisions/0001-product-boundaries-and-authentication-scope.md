# 0001：产品边界与首期身份范围

## 背景

SpeechNexus 从 SpeechRail 的语音能力与场景经验出发，面向 Linux / vLLM 环境。产品负责人明确了后端服务与 WebUI 的不同定位，并决定短期不建设用户身份认证体系。这些范围需要在接口、数据和实施顺序中保持一致。

## 决定

1. 后端定位为可独立使用的企业级语音服务底座，采用 OpenAI 兼容子集和增强协议；增强能力包括音色创作。实时与非实时 ASR/TTS 保持统一领域语义。
2. WebUI 定位为 AdminUI 与个人语音工作台，面向不同任务需求。管理功能与个人任务体验分开组织；两类受众不自动等于权限角色。
3. 短期不建设用户身份认证体系，不将登录、用户目录、角色授权或多租户建设作为首期语音能力和 WebUI 的前置工作。
4. 硬件型号与数量由实际部署验证确定，不写入公共语音能力协议。

这些决定来自 2026-10-22 的产品需求确认。网络入口、可选服务密钥、模块划分、数据表和具体协议由[项目主设计](../speechnexus-product-architecture.md)与配套设计规定，本 ADR 的 accepted 仅指上述产品范围，不表示机器契约、实现或部署资格已通过。

## 影响

- 底座应可在没有 WebUI、工作台业务模块或 LLM 的情况下提供服务；外部应用直接消费公开语音协议。
- 工作台的会议、助手、提词和有声书编排不进入底座核心；AdminUI 消费管理协议。
- 首期不能声称个人数据私有化、按人配额、角色分权、双人审核或租户隔离。“个人”表示工作方式，不构成用户安全边界。
- 企业级能力优先体现在协议、资源治理、可观测性、生命周期、版本、故障恢复和部署资格；用户身份与权限在出现明确需求后独立设计。
- 实现状态和验证范围分别见项目说明、实施计划与审查 / 验收记录。设计要求不能当作能力已实现的证据。

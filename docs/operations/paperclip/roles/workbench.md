本机进行通用开发 / 构建，真实 GPU 通过获准正式协议消费，不因页面等引擎就把通用构建迁到 GPU 节点。向非作者 reviewer / QA 交固定候选、复现步骤、协议 / 生产者版本及合成 / 真实覆盖；实际设备、采集权限和网络条件由适任验证方单独取证。

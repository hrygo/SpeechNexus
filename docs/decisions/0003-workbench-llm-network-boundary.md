# 0003：工作台 LLM 与业务内容的网络边界

## 背景

助手和会议纪要需要可选的文本生成能力，但语音底座必须可独立运行。仅规定“可选 LLM”不足以确定内容流向、部署责任及故障行为。产品负责人在 2026-10-22 明确：**仅支持本机或内网 LLM，内容不得出网。**

## 决定

1. 语音模型本地推理；工作台 LLM 仅接入部署方配置的本机或内网服务，不接入公有云推理，也不在失败时回退到外网端点。
2. LLM 集成默认关闭；未配置或不可用时，底座 ASR / TTS、音色创作及不依赖 LLM 的工作台流程仍可使用。首期不承担 LLM 模型选型、部署或实例生命周期管理。
3. LLM 凭据与端点由服务端部署配置管理，浏览器只调用工作台 API。普通请求不能指定任意服务地址。工作台明确展示将处理的内容范围，并固定所用稿件 / 转写版本、模型标识与模板 revision。
4. 音频、转写、书稿、声音参考及其派生内容不得发送到部署网络以外；日志、追踪、错误报告和浏览器资源也必须遵守该边界。生产页面使用本地构建的资源，观测数据只交给部署内收集器。
5. 内网地址本身不能证明内容没有出网。部署必须限制服务出站目的地，确认 LLM 服务及其代理不转发内容到公有云，并以受控测试提供证据。模型与镜像可在独立准备流程中取得和校验；业务运行使用已准备的制品，不用业务内容参与外部下载或诊断。
6. LLM 执行属于工作台，拥有独立任务、取消、用量与故障记录，不占用底座语音队列。若其与语音引擎共享物理设备，仍须计入同一部署物理预算和混合负载资格；无法约束的占用不能获得实时容量承诺。

## 影响

- 助手与纪要通过工作台的服务中立 LLM 端口适配已有服务；底座不依赖 LLM SDK、模型或业务 prompt。
- LLM 失败不能改写成功转写、重做已完成语音推理或自动外发内容；用户可保留已有工作并明确重试。
- 内容网络边界必须同时覆盖应用、推理服务、代理与观测链路；当前开发 Compose 尚未实现该完整部署约束。
- `accepted` 表示该产品约束已经确认，不表示 LLM 集成、出站限制或相应测试已经实现。

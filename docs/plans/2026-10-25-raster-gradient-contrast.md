# 渐变与玻璃背景栅格对比度

目标：自动核对 axe 因背景渐变无法判断的实际文字区域，替代现有位置/前景 Token 白名单，不增加依赖或 CI 作业。

- [x] RED：复现前景 Token 不变、实际背景变差时现有门禁仍通过的漏洞；增加局部坏色带、透明玻璃与跨屏文字场景。
- [x] 用 DOM Range 定位文字行，按可见 viewport 截图隐藏文字墨迹的实际背景；由浏览器解码并比较区域内每个 CSS 像素，使用未四舍五入的 WCAG 比值。
- [x] 对生成文字、组透明度、前景 filter/blend 等未覆盖效果明确失败；保留失败截图与栅格 JSON，恢复滚动及页面状态。
- [x] 复用现有 24 个页面情景及 CI 浏览器/报告链；验证运行时间、门禁负例、原有检查与独立审查。
- [ ] 提交 PR，托管验证通过后合并；交付状态以 PR 为准。

边界：Chromium、DPR=1、现有页面矩阵的静态状态。行框最差像素检查比逐字形检查保守，不承诺连续 viewport、其他浏览器、动态影像或完整 WCAG 合规。

依据（2026-10-25）：[W3C F83 最不利背景检查](https://www.w3.org/WAI/WCAG22/Techniques/failures/F83)、[Playwright screenshot API](https://playwright.dev/docs/api/class-page#page-screenshot)。

本地验证：50 项浏览器检查通过；24 个页面情景覆盖 652 个文字行、3,082,676 个背景像素，最低对比度 4.889:1，单情景最多 4 张截图。独立审阅发现的伪元素、遮罩与嵌套/相交玻璃遗漏已由负例复现并关闭。

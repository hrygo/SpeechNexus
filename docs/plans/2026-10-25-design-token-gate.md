# Design Token 轻量门禁

目标：补齐当前静态 Token 检查的可复现漏检，在不安装 Web 依赖的 CI 前置作业中阻止回归。

- [x] 用 Node 内置测试与临时仓库夹具复现：引用空白/fallback、注释伪声明、组件引用、颜色绕过、无效注册表及 primitive 漂移。
- [x] 收紧校验器：按文件类型处理注释，扫描全部 Web 消费者，严格校验项目注册表和引用闭包；保留现有业务文案、能力状态与网络规则。
- [x] CI 前置作业运行独立测试与校验；保留既有 Web lint 和受保护汇总门禁。
- [x] 本地验证与独立审阅完成，准备 PR；托管 CI 通过后合并（交付结果以 PR 状态为准）。

范围：静态字面量与当前 CSS 字符串注册表。无新增依赖，不修改视觉设计，不宣称完整 DTCG 合规、浏览器级联正确或对比度通过。遇到动态生成引用及运行时样式，由类型/浏览器测试补充。

依据（2026-10-25 核验）：[CSS Variables](https://www.w3.org/TR/css-variables-1/) 的空白、fallback 与失效语义；[DTCG 2025.10](https://www.designtokens.org/tr/2025.10/format/) 的结构化值与引用要求。当前项目使用 CSS 字符串扩展，新增不支持的别名格式应失败而非静默漏检。

验证：39 项独立 Node 回归；203 项 CI 路由与门禁回归；Web 格式、lint、typecheck、1121 项测试与两个入口构建通过。独立审阅发现的命名色漏报与 CSS content 字符串误报已复现、修复并复核。

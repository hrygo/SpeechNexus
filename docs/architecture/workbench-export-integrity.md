# 工作台导出发布前完整性检查

工作台的 `ExportWorker` 组装已保存音频，不调用推理引擎。组合根仍要求显式注入 `ExportProducer`、配置对象区并启用周期驱动；默认没有 producer，队列保持未领取。本页描述发布前检查的实现边界，不代表 C07 全范围交付。

## 发布顺序与失败事实

1. producer 按实际完成数量报告进度；回执须匹配 export、book、manifest revision、格式、总数及本次数量。producer 返回后不再接受其迟到回调。
2. 数量未完成即失败。领域 `complete()` 不补造进度，持久完成也必须已有完整进度。
3. `ExportMediaValidator` 在写入意图与对象 PUT **之前**校验全部返回字节。
4. 校验后重新确认已持久进度，识别期间接受的取消。现有 `reserve_export` 还在项目→导出锁序下复核状态，覆盖复核与写入预留之间的取消。
5. 继续现有写入意图→PUT→结算→完成路径。PUT 未知保留写入屏障；完成提交回执丢失时不补写失败。

校验拒绝、超限或超时返回稳定的 `unavailable` 错误，不泄露解码诊断、内容或内部地址。如果失败转换被已持久取消拒绝，只结算该取消；其他提交未知异常继续传播。校验线程退出后才能结算，不把取消等待当作解码已停止。

## 媒体与归档检查

- 格式与 MIME 严格配对：WAV / `audio/wav`、MP3 / `audio/mpeg`、ZIP / `application/zip`。
- WAV 检查 RIFF/chunk 长度、完整且非空的 data frame，再经 PyAV 全流解码；MP3 使用固定 demux/codec 解码。均须产生音频样本，拒绝额外视频或封面轨。
- ZIP 预检查中央目录，再读取并验证 CRC。限制实际条目数、累计展开字节与解码音频时长；拒绝危险/重复路径、加密与特殊节点；支持单卷 ZIP64。
- 所有 `.wav` / `.mp3` 成员均须解码，其数量须等于 export 的 `progress_total`。可选元数据同样计入展开预算；识别到元数据开头的 WAV/MP3 标记时保守拒绝，但这不构成任意隐藏内容检测。

解码成功只证明本次检查覆盖的容器、样本和成员数量。相同数量的错误单元仍须由完整固定清单检查；完整音频截短而重新封装也不能仅凭解码识别。内容身份、版本、听感和质量另行验收。

## 配置与资源边界

以下 `WorkbenchSettings` 字段使用 `SPEECHNEXUS_WORKBENCH_` 环境变量前缀，字段名转大写：

| 字段 | 默认值 | 单位/范围 |
| --- | --- | --- |
| `export_max_output_bytes` | 268435456 | 输入成品字节；1–2⁴⁰ |
| `export_max_unpacked_bytes` | 536870912 | ZIP 累计展开字节；1–2⁴⁰ |
| `export_max_archive_entries` | 1024 | 含目录与元数据；1–100000 |
| `export_max_audio_seconds` | 36000 | 累计解码秒数；大于 0 且至多 604800 |
| `export_validation_timeout_seconds` | 30 | 协作期限秒数；大于 0 且至多 300 |

校验在线程中执行，在读取、解压、packet/frame 边界检查期限及停止信号；重复取消也等待线程退出。原生 codec 调用须先返回，因而期限不是硬 CPU 截断。返回成品已经在 producer 内存中，输出大小限制不能约束 producer 生成前的分配；解码器内部内存、进程/磁盘预算、并发调度仍需单独治理。这些默认值不是目标部署、模型质量或容量资格阈值。

## 验证与剩余条件

媒体单元测试使用可解码的合成音频，覆盖 MIME/格式错配、截断、CRC/路径/ZIP64、缺成员、展开/时长/数量限制及取消清理。worker 测试另覆盖未完成进度、错身份回执、晚回调、校验与取消交错，以及完成/失败提交回执丢失。隔离 PostgreSQL/MinIO 与 runtime 测试验证持久进度、发布前零写入意图/零对象及实际组合根配置；只有执行通过后才能作为对应证据。

完整不可变单元/版本/source receipt 清单、检查点与崩溃续作、正式 saved-audio producer、公开二进制下载/SSE 消费、预算治理及真实质量/试听/匿名确认仍需交付。真实 Job/Artifact 制品与模型、物理设备、目标拓扑的联合验收不能由这些合成测试代替。完整要求保留于 [C07](https://github.com/hrygo/SpeechNexus/issues/42)。

# 需求矩阵与当前交付

当合并结果影响产品需求或相关交付时读取本页，按已授权范围同步。

- [总控 #336](https://github.com/hrygo/SpeechNexus/issues/336)下的十个 Epic 维护产品范围及接收；每个实施 issue 有唯一原生主 Epic。
- [PRD](../../../../docs/prd.md)、相关设计与[需求矩阵](../../../../docs/plans/delivery-tracking.md)共同覆盖完整产品范围；[结构化关联源](../../../../docs/plans/delivery-issues.json)记录需求与当前交付关联。没有实施 issue 的需求仍保留在矩阵，不因此判定遗漏或自动建卡。
- 按实际合并证据更新受影响需求的实现、集成、验证与证据；需要时更新当前实施 issue 关联。区分组件、生产接线和真实验收，不因合并或 CI 通过自动结算完整需求。
- 更新前核对现有 diff 与来源；按仓库当前工具和格式更新、验证矩阵及结构化关联源，不假定机器字段、标记或 schema 版本。保留他人改动；工具或数据不可用时保留旧输出并报告，不猜测状态或扩大远端维护范围。
- 原生关系与需求主归属不一致时说明具体差异；只在已有授权覆盖时修正并回读，不用正文链接代替关系。

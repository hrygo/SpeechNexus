# 实时路径 SLO 表(冻结)

本表固定 #1097 实时路径的指标口径。`状态`列只有三种取值:`已实测`(有 commit、窗口与样本数)、
`未验证`(没有可复现实测,不得当成通过)、`未覆盖`(该路径未实现或不在首发范围)。首发数据库是
PostgreSQL;本表不声明任何非 PostgreSQL 目标的容量结论。

## 故障窗口

| 场景 | 期望行为 | 状态 |
| --- | --- | --- |
| 数据库延迟抬升(< credit 余量) | 消费现有 credit,无输入 gap | 未验证 |

| 主备切换窗口 | 探针代次/Schema 不符即拒绝授予,不超发 | 部分:代次复核有单点实测,切换窗口未验证 |

## 未覆盖项

- 实时引擎、浏览器与目标设备的端到端联验未执行:首发只完成契约与 PostgreSQL oracle。
- 双工 + batch 的公平性只在账本层单点验证,没有并发压测分布。
- 数据库贡献与端到端延迟尚未分开采集;表内全部为 `—` 是「没有实测」,不是「达标」。

## 更新规则

跑出实测后,在同一 commit 内填入口径、窗口、样本数与失败率,把 `状态` 改成 `已实测`,并在
PR 里给出原始数据位置。没有新实测不得改状态,也不得用单次读数代替稳态。

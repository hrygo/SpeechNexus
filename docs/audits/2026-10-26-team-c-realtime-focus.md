# C04：实时操作后的键盘焦点恢复

2026-10-26，初始基于 main `15d91f8635ade9b134f4e3fe0c1a95523b35cb29`（PR #184），最终 rebase 到 `7851cfb46a9a19166c6ef5df3c42d2bc6363a5b8`（PR #185），对应 [C04 #39](https://github.com/hrygo/SpeechNexus/issues/39) 的局部键盘/焦点条件。此前生产页面创建后焦点落到 BODY、采集后留在 disabled 按钮的失败记录继续保留。

## 行为与边界

ASR/TTS 共用实时工作区内的焦点修复：原聚焦控件因创建、原键重放、连接、媒体启动、提交/取消或断线变为不可用或被移除时，在布局提交后聚焦稳定的工作区标题。标题可编程聚焦，后续 Tab 继续访问可用控件。

只修复仍属于该工作区的失效焦点。用户移到其他控件或工作区、点击页面外部、窗口失焦、页面隐藏或功能非活动时，不因异步结果返回而抢焦点。输入仍需显式提交和开始，未更改协议、恢复键、媒体生命周期或存储边界。监听器随活动状态与卸载清理，只保留一个本地焦点引用。

## 评审后续单元：取消下载的焦点归属

2026-10-26，head `d75880a` 的评审要求为取消下载定义正确行为并补确定性用例：此前实现只在 `busy` 变为 false 时无条件把焦点拉回下载按钮，能恢复“焦点仍留在已移除的取消控件”的键盘连续性，但取消收尾延迟时，用户移到其他控件、点击组件外部、窗口失焦或页面隐藏都会被抢焦点。

行为定义：只修复本次过渡（取消→取消控件卸载、下载按钮重新启用）造成的焦点丢失。取消时记录当时属于本组件的焦点控件；此后用户聚焦其他控件、点击组件外部、窗口失焦或页面隐藏即解除该归属。收尾时仅当原控件已不可用（卸载/禁用/隐藏/被 inert 包裹）且当前焦点仍落在原控件或 BODY 上，才在布局提交阶段精确聚焦重新启用的下载按钮。未更改公开协议、取消时机、abort 语义、无 alert/status 断言与默认期限。

# 契约集成

负责 SpeechNexus 公开契约、生成链、权威状态 / 协调事务、持久恢复和生产装配。

## 实施边界

- 先固定生产者 / 消费者契约，再实施并生成或校验类型；只改权威源，不手改生成产物或维护第二份 DTO 语义。按改动读取契约、协调或恢复技能。
- PostgreSQL 承担正式权威状态；准入、预算、租约及 Job / outbox 维持原子事务与固定身份恢复，不拆成跨模块双写。共享契约、迁移、生成物和组合根由指定写者串行接入。
- 向 GPU 执行岗交固定资源版本、有效命令、输入资格及正反时序样例；向工作台交公开协议、生成客户端与错误 / 恢复样例，取得消费者实际接入结果。
- 本机先做适用静态、合成与装配检查；Linux、CUDA 或隔离持久验证由获准环境按同一候选取证。本机成功不替代目标环境资格。

## 实施交付

交最终候选、契约 / 迁移关系、生产接线、原始结果和未验项。高风险改变交非作者 Sol 与对应环境验证；可审查本人未参与的执行层候选，不换岗自签。

## 本轮 Goal

在 **2026-10-26 至 2026-11-08** 的规划时间盒内，先贯通可恢复的真实文件 ASR 公开链，
再复用同一持久协议贯通 CustomVoice TTS：
**固定输入与有效配置→完整公开 Job/全配方原子准入→B 唯一执行→持久回执→A 受控发布→标准 SDK/C 消费。**

日期是本轮目标窗口；10 月 28 日前根据具名制品、环境与可用容量核实排期，缺输入明确改排，不以假数据达标。

### 可衡量的完成条件

- **KR1 真实公开闭环 0/2→2/2。** ASR 包含上传、真实 ready、转写、公开下载及 C 原稿导入/校对/固定版本导出；
  CustomVoice 包含固定文本/内置声音、真实音频发布、标准 SDK 与 C 试听/下载。先 ASR 后 TTS，同版逐链计数。
- **KR2 冻结故障矩阵 12/12 有效证据。** 按复盘 F01–F12 验正常/静音/格式、损坏/超限、原键冲突、
  上传/Job/发布确认丢失、取消/迟到、重启、两逻辑节点竞争、停止释放与首资源删除。子条件全部满足才通过；
  合成组件测试只作支撑，完整公开链未验的项目保持未运行。
- **KR3 验收期间关键不变量违规为 0。** 不重复执行/发布，不以 unknown、超时或取消退预算，
  不越权、不把无效音频标 ready。当前真实链未测，不能把未知基线写成 0。

证据携带共同 integration SHA、契约/生成器、模型/镜像/资源 revision、语料摘要、拓扑、
操作与预期/实际结果、原件位置及未验证项；逻辑节点和物理多机资格分列。
本轮 KR 完成只构成阶段成果，不能据此宣布 A00–A07 全部完成或自动关闭 Gate。

## 首个执行单元与推进顺序

1. **M0 核实事实和输入。** 只读核对 #201 合并/CI 及 #155/#201 清理回执；
   实施开始时按真实合并事实同步 A issue。固定 B 媒体制品、首个权威绑定、参数/输入输出上界及目标环境。
2. **M1 真实音频 AssetInspector。** A 负责独立共享媒体制品打包/消费，B 保留 codec 语义和资格；
   固定原实现/源映射/镜像后，接 #155 受限进程及现有 HTTP/PG/MinIO 资产路径。
   不导入整个 gateway wheel、不复制 decoder；公共错误/媒体投影先冻结源契约。
   验全量解码、原键/固定对象版本/7 天 TTL、损坏/截断/超限、取消/重启/丢确认。
   缺目标资格或旧进程停止证据时保留不可用/占用，不假 ready；raw PCM 不从裸字节猜格式。
3. **M2 真实 ASR Job 与发布。** 接纳固定权威 binding/readiness/有效参数，装配业务 Worker；
   复用完整配方、quota、父预算、全部 leases 与 Job/outbox 同事务，六字段 JobFact 不冒充公开 Job。
   消费 B #142 持久回执，交付 Artifact/receipt/Operation/事件及公开下载，由 SDK/C #37 同版消费。
4. **M3 CustomVoice 第二条链。** 复用 M2 协议，接固定文本/内置声音与真实音频回执。
   B 先交付 #203 请求硬上限问题修复及原始探针证据，A 不绕过。
   验默认 MP3、显式 WAV/PCM，补取消/恢复、发布和停止/释放；不混作 Base/VoiceDesign 或实时资格。
5. **M4 联合交接。** 逐项回填既有工作包 AC 和 G0/G1 材料；部分完成保留父包开放，前置 Gate 不跳过。

当前主写入队列为 M1，不为已合入 SDK/词典读取重开重复任务。M0 可先行；
媒体制品待交时继续已授权的权威配置/Job 独立前置。
每轮一个主要写入单元，共享源、生成器、锁、迁移与组合根串行。

## 依赖与权限边界

| 所需输入 | owner | 解除条件 |
| --- | --- | --- |
| 共享媒体制品/inspection 入口 | A 打包/接线，B codec | 固定源映射、可获取制品、目标 sandbox 内实际 decoder 资格 |
| ASR/CustomVoice 权威绑定与执行 | B #142；A 接纳 | 模型/镜像/显式参数/上下界及可信 provider；草稿注册不算发布资格 |
| 私有回执、可信停止/释放事实 | B；A 原事务结算 | 原身份可查，双证据齐备后一次退预算；unknown 保持占用 |
| 公开消费与浏览器/导出证据 | C #37/#42/#43 | A 固定公开端点/凭据引用、同版 SDK/真实模型结果；C 提供自有证据 |
| 物理拓扑/设备与恢复环境 | B/运维、A 联合 | 目标隔离资源就绪，物理资格不由单机逻辑节点替代 |

每项阻塞写 owner、所缺版本/制品、影响和解除条件；继续独立工作，无可继续项时报告阻塞，
不无限重复检查或以 fake/原型替代真实资格。A 维护本队及适用总控，C issue 由 C 维护。
PostgreSQL 是正式产品数据库，InnoDB 只验证共享协调路径，不引入第二预算权威。
内容不出部署网络，LLM 默认关闭、仅批准内网，无公有云回退。
Git、生产权限/DDL/部署、GPU、删除及运行态按适用授权执行；
已消费的一次性 #155 策略实验不重新启用，本目标不扩大权限。

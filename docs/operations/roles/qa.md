# 独立验收

验证最终固定候选的正式消费者行为，交付可复现的验收结论；不代作者修改实现。

## 验收范围

- 先取得候选与原验收条件，确认 SHA 或 base + 完整补丁与受检版本一致；按风险选择 SDK、浏览器、故障及设备场景，不为文档任务固定运行整套矩阵。
- 重点验证幂等重放、丢确认 / 重启、取消未知、迟到响应、过期和下载完整性。真实语音通过获准公开协议消费正式生产者；页面可打开、fake 或健康检查各自只证明实际覆盖范围。
- 在任务指定的独立轻量环境串行检查，一次一个浏览器 / 设备窗口，不加载本地大模型或运行重型全库负载。设备权限、真实后端和物理多机分别取证。

## 验收交付

列出版本、环境、场景、expected / actual、原始证据及通过 / 失败 / 跳过 / 未运行；失败交原作者返修，候选变化后补验受影响部分。接收者须取得报告与必要原件并记录结论；QA 无需为报告创建 PR。运行验收与代码审查分开，不代签非作者 Sol 审查或用户 Gate。

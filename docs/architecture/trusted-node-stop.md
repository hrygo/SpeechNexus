# 节点停止事实到网关的可信消费

网关已有 `InstanceTerminationEvidencePort`、有界恢复扫描和 `record_stop` 事务，
但此前生产者只有测试替身。节点已有[原 stop 检查点恢复](node-stop-recovery.md)，
外部快照也已收窄为诊断。本单元把节点的持久双证据接入现有网关消费路径，不新增预算权威。

## 生产者与消费者

机器契约是 [runtime-control](../../contracts/internal/runtime-control.openapi.yaml) 的
`getVerifiedInstanceStop`。节点按实例和 generation 只读查询，成功响应复用完整原 stop 回执：
必须有原请求完全相同的 released 检查点，容器 ID、退出码和释放时间与回执证明一致。
旧版可能采信过外部快照，因此没有本地检查点的旧成功回执仍不能出具可信事实。
多个可用原 stop 不任意取最新；冲突、损坏或歧义保持不可用，不自动修复、覆盖或删证据。

| 节点状态 | 查询结果 | 网关行为 |
| --- | --- | --- |
| 无回执、未决/隔离、只有 target/exit 或无检查点的旧成功回执 | 404，原错误码 `runtime_intent_not_found` | 保持 unknown 和占用，不把 404 当成停止 |
| 原 stop 成功，检查点 released，全部字段一致 | 200，原回执，不含 POST 重放标志 | 校验绑定、身份、任期及时间后才生成整实例事实 |
| 检查点/回执矛盾、重复可用来源或存储不可用 | 503，`runtime_controller_unavailable` | 保持未知，不改原记录 |
| 其他节点、非法路径、缺凭据 | 原 409/422/401 错误信封 | 不出具事实，不重试或切换端点 |
| 再次读取、同库重启 | 同一原证明及时间 | 同一来源 ID/摘要；既有 ledger 派生每执行 ID |

这个 GET 不调用 daemon、不推进 stop，也不补回执。节点自身观察循环负责恢复原 stop。
调用方必须先等它持久完成，再查询；诊断名单、断连、超时和取消不能触发任何释放。

## 网关来源适配

适配器只接受服务端固定的私网 IP、节点 TLS/CA、组件凭据与不可变绑定配置。
查询参数来自已持久执行，不接受业务请求指定端点、证书、凭据或任意 stop ID。
响应必须匹配 node/gateway/pool、实例/generation、binding revision、批准模板、manifest、
config digest。stop token 只与同池该执行 token 比较，不得低于它，不产生节点级 token 高位。
证明必须不早于该执行记录/外发且不晚于消费者当前时间。

传输仅一次 GET，无重试、代理、重定向或公有网回退；TLS 必须验证证书和 IP 身份。
整个调用、并发和 JSON 体积有上界，重复字段、压缩、畸形/超量响应与无关身份均不能形成证明。
同步恢复端口在工作线程调用异步有界请求，网络等待不占数据库事务。
配置和客户端 repr 不暴露地址、凭据或私有绑定材料，错误不包含响应正文。

来源 ID 绑定 node 与原 stop ID，摘要覆盖规范化的完整回执及来源版本；
同一证明可覆盖同实例代次的多个执行，沿用已有 `whole_instance_stop_evidence`
派生执行专属证据 ID，再由 `record_stop` 原子关闭原执行。查询不释放预算；
网关也不改 A 的 lease/quota/节点预算，A 后续独立事务消费停止事实。

## 兼容与接入

内部契约新增一个 GET，既有路径/字段/错误码不变。A 的原意图 submit/GET 客户端不变；
生成器不改，只扩充既有 runtime HTTP 选择清单并重新生成、验证所有消费类型。
旧节点缺少该路径时视为无证明，保留占用；先升级节点，再启用网关来源配置。
回退关闭来源适配即可，不删除检查点或回退数据库版本；旧事实不会被追溯认证。

网关复用现有恢复扫描，并由同一服务实例保留本地ID游标连续访问、空页后绕回；
不会改未知事实来推进队列，计数也不把用量version变化重复算作状态观察。
默认进程的引擎 adapter、周期驱动及部署配置仍需后续装配。
原生 HTTP/TLS、SQLite/网关 PG 与 A 的双库消费者验证分别报告；fake daemon 和
合成资格不代表真实 GPU 停止、真实 ASR/TTS 故障或物理集群资格。集群要求不降级。

分层验证和可复现命令见[本轮实测记录](../audits/2026-10-24-b02-trusted-node-stop-probe.md)。

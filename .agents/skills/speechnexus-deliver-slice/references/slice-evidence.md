# 切片映射与证据判定

用于跨团队交接、多个 AC 或证据层次容易混淆的任务。沿用现有任务/报告格式，只有信息复杂到需要时才建矩阵，不额外生成一套平行台账。

## 一条条件应能回答什么

| 问题 | 应记录的内容 |
| --- | --- |
| 究竟要求什么？ | 原 AC 标识、原文和当前范围决定；复合条件的子标识保留父级含义 |
| 预期由谁规定？ | 源契约/有效 ADR 与相关字段、状态、错误语义 |
| 实际在哪里发生？ | 生产用例、权威状态、组合根以及用户可到达的消费者 |
| 什么会使验证失败？ | 业务断言，包括应保持或禁止的副作用、身份、版本和恢复结果 |
| 跑的是什么？ | 实际执行入口、代码版本或工作树快照、输入、依赖版本和拓扑 |
| 能得出什么结论？ | 结果、证据位置、覆盖边界、未测项、具名依赖及下一步 |

只有某字段对判断有意义时才填写；文件/符号/摘要可作为定位和保鲜手段，不能充当运行证明。代码改变后按影响重新验证，不能仅刷新摘要。

## 避免把证据排成一个虚假的单一等级

| 已取得证据 | 能证明 | 仍需另证 |
| --- | --- | --- |
| schema、生成检查、正负例 | 声明和形状一致；覆盖到的语义约束 | 路由已注册、授权角色可运行、业务链路成立 |
| fake adapter、HTTP fixture、DOM 测试 | 被隔离的应用/消费者逻辑 | 真实持久结果、网络故障、浏览器和设备行为 |
| 实际 Chromium + 合成服务 | 实际浏览器里的指定交互和传输 | 实际生产者持久状态、真实引擎质量 |
| 隔离生产数据库/对象区 + 合成 producer | 实际迁移、权限、事务与对象行为的指定路径 | 真正引擎、目标宿主/版本、集群和负载资格 |
| 真实模型/引擎 | 固定模型、绑定和样本上的指定行为/质量 | 其他模型、设备、拓扑及长期容量 |
| 目标部署/设备故障验证 | 指定部署及故障条件内的结果 | 没有实际覆盖的网络、并发、时长和恢复路径 |

服务、模型、浏览器、设备和拓扑是不同证据维度。一个真实维度不能补齐另一个未测维度；例如真实浏览器消费 fixture，仍没有真实生产者证据。

## 常见断点的下一动作

- **契约有声明，产品无路由**：标明声明已交付、生产能力未交付，接收具名生产制品后联调。
- **组件测试通过，正式页面未挂载**：补正式装配及可到达性验证，保留既有组件测试边界。
- **adapter 可注入，运行时没装配**：检查真实组合根和配置；不能以测试构造的实例冒充默认服务。
- **探针被引用但没有执行**：核对实际调用、结果和场景断言；必要时用保留引用而移除调用的反例验证守卫。
- **主线门禁发现协议变化**：保留失败，形成版本/迁移、生产者和消费者升级方案；不换 base 或松校验求绿。
- **新证据只覆盖旧 AC 的一部分**：更新实现摘要和子条件证据，保留父 AC 未通过。

## 维护与评测

当契约、组合根、部署边界变化或真实任务暴露误判时复测对应场景。比较启用技能和基线的实际产物与执行过程，检查漏项、范围漂移和无效工作；不要用“包含了某个标题/措辞”判定技能质量。

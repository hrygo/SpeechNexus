# ADR 0006 集群协调与存储可移植性

## 背景

现有 PostgreSQL 协调草案使用数据库函数、延迟约束触发器、容量验证队列及
区间排他约束实现协调规则。这些机制已有隔离 PostgreSQL 验证，但使规则实现
和数据库绑定，增加后续迁移成本。当前业务运行时尚未实现，适合在落地前调整边界。

用户已确认：集群部署支持不可降级，单节点仅为当前环境；项目协调不采用 etcd；
PostgreSQL 为唯一正式交付数据库，MySQL/InnoDB 用于关键协调行为的迁移验证；
跨表规则的主要执行边界可以迁入受控应用事务，不再要求数据库独立拦截所有
绕过应用层的直接 SQL 违例。

## 决定

1. **集群能力保持完整。** 多副本 API、分池 Scheduler owner、多 Worker、
   会话 owner/epoch、节点级执行网关与受限控制器从设计和实现上支持集群。
   Node=1 使用同一套协议、持久状态和恢复机制，不采用单机专用协调路径。
2. **应用层维护协调规则。** 预算计算、状态转换、停止证据要求和恢复裁决由领域
   与应用用例负责；基础设施适配器负责事务、锁、条件更新和持久化。
   所有正常运行写入经过明确的原子操作，不开放通用的任意状态更新入口。
3. **明确保护边界的变化。** 数据库保留事务原子性、唯一性、必要外键、行内
   约束、历史保护和最小权限。应用事务必须保证跨表不变量，检查失败回滚整体操作；
   不再承诺数据库能独立识别所有绕过受控入口的直接 SQL 违例。该变化减少了数据库
   对应用漏检的独立兜底，必须以共享行为测试、真实事务竞争及故障测试验证替代路径。
4. **保持单一事务权威。** 一次完整容量准入涉及的配额、节点/实例预算、全部
   stage 租约位于同一关系数据库事务域。Job 与 outbox 保持同事务；
   网关写停止证据与 Scheduler 释放预算仍是各所有者的独立短事务。
   表所有权和独立进程部署不等于跨独立数据库双写。
5. **隔离数据库特定机制。** 正确性依赖多行事务、条件更新、受控锁定与唯一
   约束等明确能力。`SKIP LOCKED`、数据库通知等可作为适配器优化，
   不得成为缺少等价实现时仍可声称支持目标数据库的理由。
6. **限定数据库支持范围。** PostgreSQL 是唯一正式产品适配器；
   MySQL/InnoDB 只验证 owner 接管、完整容量准入、任务认领、执行去重、
   停止后释放及其竞争/故障语义。通过这组测试不等于全产品支持 MySQL，
   也不证明可以零成本迁移到任意数据库。测试版本在实施时锁定。
7. **不引入第二协调权威。** 不采用 etcd，也不为其建立适配器或部署服务。
   Redis 仅可选用于非权威缓存和唤醒；关闭或丢失通知时由持久记录与轮询恢复。
   不以 Redis 租约到期、连接断开或心跳失效作为引擎停止及预算释放证据。
8. **执行边界继续负责 fencing。** 数据库 token 不能撤回已经外发的引擎请求。
   接管须封锁旧入口并协调在途执行；未知执行继续 quarantine。
   数据库不可用或故障切换后协调水位不确定时停止新准入，先恢复可信事实。

## 与既有决定的关系

- 保留 [ADR 0004](0004-cluster-ready-architecture-and-single-node-mvp.md) 的
  集群拓扑、三级资源预算、跨层级原子准入、所有权与网关屏障要求；
  PostgreSQL 专用认领和租约写法调整为适配器实现选择。
- 保留 [ADR 0005](0005-complete-execution-and-data-lifecycle-contracts.md) 的
  执行命令、公开投影、错误恢复、删除生命周期、历史和停止证据要求；
  数据库独立执行所有跨表规则、延迟容量验证队列等实现要求由本决定替代。
- 公共和内部机器契约的状态、错误、身份、版本、摘要、预算单位与时序继续有效。
  本决定不授权通过修改协议或删减反例掩盖不兼容。
- 节点级高可用、数据库恢复和实时会话恢复的实际资格仍须按目标部署验证；
  本决定不新增未经测量的 RPO/RTO，也不把集群能力推迟到单节点交付之后。

## 实施与验收

按[集群协调重构计划](../plans/2026-10-23-cluster-coordination-refactor.md)分阶段
冻结事务契约、实现隔离原型并验证，再替换 PostgreSQL 草案机制。
精简目标 DDL、应用事务方案与双库测试原型已交付；旧 DDL 和测试另存历史 fixture。
这些交付不能被视为生产 Scheduler、完整生命周期或集群故障资格已经实现。
公开协议兼容、真实数据库并发/故障行为及集群场景共同构成验收，SQL 行数不作为指标。
